  - *Детали:*
    - Создать модель `TbArticleAlias` (`s_old_slug = SlugField(unique=True, db_index=True)`, `k_article = ForeignKey(TbArticle)`).
    - При изменении `s_article_slug` в админке автоматически сохранять предыдущий слаг в `TbArticleAlias`.
    - В `UniversalSlugView` добавить двухэтапный поиск:
      1. Поиск по `TbArticle.s_article_slug` -> если найден, рендерим (или 301 на канонический URL).
      2. Если не найден, поиск по `TbArticleAlias.s_old_slug` -> если найден, рендерим `HTTP 301 Permanent Redirect` на актуальный URL статьи.
      3. Если не найден нигде -> `HTTP 404` (с блоком-подсказкой для `request.user.is_staff`).
